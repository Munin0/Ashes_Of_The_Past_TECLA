Detailed Description

Input manager: polls the SDL events and answers input queries.

PollEvent is a singleton that reads the pending SDL events once per frame and keeps the state of the keyboard, the mouse and the gamepad, so the rest of the engine and the game can ask about it without dealing with SDL events directly.

For keys and mouse buttons, it keeps the state of the previous frame, which allows telling apart three situations:

  • Press: the key or button went down in this frame.
  • Down: the key or button is currently held.
  • Release: the key or button went up in this frame.

Usage:

ENG::PollEvent& input = ENG::PollEvent::Get();
input.ResetPollEvent();
input.ProcessPollEvents();
if (input.IsKeyPress(SDL_SCANCODE_SPACE))
Jump();
