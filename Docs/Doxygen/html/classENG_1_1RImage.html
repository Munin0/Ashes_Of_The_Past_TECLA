Detailed Description

OpenGL 2D texture created from an image file.

RImage represents an image that lives on the GPU. It stores the path and the name of the image, and owns the OpenGL texture created from it: the texture is deleted when the RImage is destroyed.

Usage:

ENG::RImage image("player.png", "player");
image.LoadImage();
if (image.IsValid())
image.Bind(0);
