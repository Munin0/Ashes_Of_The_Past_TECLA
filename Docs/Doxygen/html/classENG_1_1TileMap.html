Detailed Description

A tile layer of a map exported from Tiled, ready to be drawn.

A TileMap holds the grid of tiles of a single tile layer. Each cell references a tile of an atlas that was uploaded to the TextureArray, and the texture coordinates of the tiles are resolved once when the map is loaded, so drawing only needs to walk the grid.

TileMaps are normally created with LoadTiledMap(), which returns one TileMap per tile layer of the Tiled map.

Usage:

std::vector<ENG::TileMap> layers = ENG::TileMap::LoadTiledMap("world_atlas", "maps/level1.json");
layers[0].SetLayer(LAYER_BACKGROUND);

std::vector< TileMap > ENG::TileMap::LoadTiledMap ( const std::string & atlasKey,
const std::string & mapPath,
float scale = 1.0f )
static

Loads a map exported by Tiled.

Parses a map JSON exported by Tiled and returns one TileMap per tile layer, in the same bottom-to-top order as the file's "layers" array.

The atlas given by atlasKey must already be loaded (see Services::Assets().LoadAtlas()), and the "id" of its tiles must line up with (gid - firstgid) for the map's (single) tileset.

The draw-order layer of every returned TileMap defaults to 0. Use SetLayer() and GetName() to assign the right LAYER_* value to each Tiled layer before handing them to Scene::AddTileMap.

Parameters
[in]atlasKeyKey of the atlas that contains the tiles of the map.
[in]mapPathPath of the map JSON file, relative to the assets directory.
[in]scaleScale applied to the tiles when drawing. Defaults to 1.0.
Returns
One TileMap for each tile layer of the map, from bottom to top.
