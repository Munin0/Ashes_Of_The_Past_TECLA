Detailed Description

Rendering and window manager of the engine.

Render is a singleton that owns the SDL window, the OpenGL context and the Batcher used to draw. It also handles the screen size and the fullscreen state.

Access the instance through Render::Get() and release it with Render::Destroy() during engine shutdown.
