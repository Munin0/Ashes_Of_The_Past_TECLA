Detailed Description

2D vector of floats.

Vector2 stores an { x, y } pair and provides the basic arithmetic, comparison and utility operations used across the engine for positions, sizes, directions and velocities.

It can be serialized to and from JSON (nlohmann::json) as { "x": ..., "y": ... }, and it converts implicitly to glm::vec2.

Note
Comparisons use exact floating-point equality (no epsilon).
