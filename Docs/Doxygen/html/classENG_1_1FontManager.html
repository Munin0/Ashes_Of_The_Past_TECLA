Detailed Description

Stores the fonts loaded by the engine.

FontManager owns every Font it receives and lets the rest of the engine retrieve them by name, so a font is loaded once and shared.

Usage:

fonts.LoadFont(std::make_unique<ENG::Font>("roboto"));
ENG::Font* font = fonts.GetFont("roboto");
