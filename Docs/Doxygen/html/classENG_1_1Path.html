Detailed Description

Central access point for the engine's directories and file reading.

Path is a singleton that resolves the location of the engine's resource directories (assets, shaders, config and data) starting from the directory of the executable, so resources can be found regardless of the current working directory. It also provides helpers to read whole files into memory.

Usage:

std::string src = ENG::Path::Get().ReadFileString(ENG::Path::Get().ShadersPath / "basic.vert");
