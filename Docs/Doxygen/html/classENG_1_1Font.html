Detailed Description

Bitmap font loaded from disk.

A Font is made of an atlas texture (RImage) that contains the rendered characters, plus a table of Glyph entries that describe where each character is inside that atlas and how it must be laid out. The glyph data is read from a JSON file.

Fonts are meant to be used by the text system (see TextAPI) to draw and measure text.
