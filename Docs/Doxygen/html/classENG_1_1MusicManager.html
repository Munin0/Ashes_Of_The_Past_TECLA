Detailed Description

Loads, plays and controls the music of the game.

MusicManager creates an SDL_mixer mixer on the default playback device and keeps every loaded music track under a string key, so it can be played, stopped and adjusted by name.

Usage:

music.Init();
music.LoadMusic("theme.ogg", "theme");
music.PlayMusic("theme");

◆ Init()

void ENG::MusicManager::Init ( void )
inline

Creates the mixer on the default playback device.

Must be called before loading or playing any music. The SDL audio subsystem and SDL_mixer must be initialized beforehand.

Warning
The result is not checked: if the mixer cannot be created, the internal mixer stays as nullptr and no error is reported.
