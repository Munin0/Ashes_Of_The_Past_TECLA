Detailed Description

Base class of every object in the game world.

An Object has a name, a layer, a transform, stats, a list of bounding boxes and a set of components (sprite, animator, material, etc.). It can be updated every frame, drawn through the Batcher, and saved to / loaded from an ObjectState.

Derived classes (for example Text, GLine or GRectangle) customize the behavior by overriding Draw(), Update(), Save() and Load().

Usage:

ENG::Object player("player");
player.SetPosition(100.0f, 200.0f);
player.AddBoundingBox({32.0f, 32.0f});
