Detailed Description

OpenGL shader program built from a vertex and a fragment shader.

Shader compiles the given GLSL sources, links them into an OpenGL program and exposes the program handle so it can be used for rendering. It also keeps the location of the view-projection uniform.

Note
An OpenGL context must be current when a Shader is created, because compilation and linking are done in the constructor.

◆ CompileShader()

GLuint ENG::Shader::CompileShader ( void )
inlineprivate

Compiles the vertex and fragment shaders and links the program.

Private because it is only meant to be called from the constructor.

For each non-empty source it creates, compiles and attaches the shader to the program, then links the program. Every step is reported through the log. The intermediate shader objects are deleted once the program is linked, and the internal shader counter is incremented on success.

Returns
true if the program was compiled and linked successfully, false otherwise.
Warning
It is declared as returning GLuint, but it only returns true (1) or false (0).
