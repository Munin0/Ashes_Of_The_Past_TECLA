Detailed Description

Base class that connects a game with the engine.

GameLayer defines the hooks the engine calls during its lifetime: initialization, input, update, fixed update, render and shutdown. A game derives from GameLayer and overrides the hooks it needs; every hook has an empty default implementation, so none of them is mandatory.

The game layer is given to the Engine at construction and is owned by it.

Usage:

class MyGame : public ENG::GameLayer
{
public:
void OnInit(void) override { }
void OnUpdate(float dt) override { }
void OnRender(float dt) override { }
};
