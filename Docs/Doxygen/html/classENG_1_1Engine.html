Detailed Description

Main class of the engine.

Engine ties everything together: it owns the game layer and all the engine subsystems (assets, scenes, fonts, audio, shaders, world saving, clock and CSV data), and drives their lifecycle through the On* functions.

Expected lifecycle:

  1. Construct the Engine with an EngineConfig and a GameLayer.
  2. Call OnInit() to initialize the engine.
  3. Call OnRun() to run it.
  4. Call OnDestroy() when the engine is closing.
Note
The Engine does not own the EngineConfig it receives; the caller must keep it alive for as long as the Engine exists. The GameLayer, on the other hand, is owned by the Engine.
