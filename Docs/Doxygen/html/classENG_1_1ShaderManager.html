Detailed Description

Stores the shaders used by the engine.

ShaderManager creates and owns every Shader and lets the rest of the engine retrieve or use them by a string key, so each shader program is compiled once and shared.

Usage:

shaders.Load("basic.frag", "basic.vert", "basic");
shaders.Draw("basic");
Note
An OpenGL context must be current when a shader is loaded, because it is compiled at that moment.
