Detailed Description

Pixel data of an image loaded from disk.

ImagePixels owns the pixel buffer returned by stb_image and frees it automatically (RAII) when the object is destroyed.

The buffer is tightly packed, with width * height * channels bytes.

Note
It is not copyable, to avoid a double free of the stb_image buffer. It can be moved.
