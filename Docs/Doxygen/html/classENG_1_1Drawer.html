Detailed Description

Immediate drawing helpers for basic shapes and textures.

Drawer groups static functions to draw lines, rectangles, circles, triangles, polygons and textures directly, without creating an Object. It is meant to be used while a frame is being drawn.

Usage:

ENG::Drawer::DrawRectangle({100.0f, 100.0f}, {50.0f, 30.0f}, ENG::Color::Red);
ENG::Drawer::DrawCircle({200.0f, 150.0f}, 25.0f, ENG::Color::Blue, 32);
