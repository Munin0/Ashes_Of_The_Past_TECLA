Detailed Description

Transparent string hasher for unordered containers.

StringHash lets an std::unordered_map (or std::unordered_set) keyed by std::string be searched with a std::string_view or a const char* directly, without creating a temporary std::string for every lookup. This makes searches more efficient.

All the overloads hash the same characters, so a string produces the same hash regardless of the type it is passed as.

To enable heterogeneous lookup, the container must also use a transparent equality comparator such as std::equal_to<>:

std::unordered_map<std::string, int, ENG::StringHash, std::equal_to<>> map;
map.find("player"); // No std::string is created.
Note
Heterogeneous lookup in unordered containers requires C++20.
