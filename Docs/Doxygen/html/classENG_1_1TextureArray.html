Detailed Description

OpenGL 2D texture array that stores many images as layers.

TextureArray reserves space on the GPU for a fixed number of layers of the same size and lets images (for example, atlases) be uploaded into them one by one. A shader can then pick any layer with a single sampler, which allows drawing sprites from different atlases in the same batch (see Vertex::ArrayLayer).

Usage:

ENG::TextureArray array;
array.Init(2048, 2048, 8);
int layer = array.UploadLayer(pixels, 512, 512);
array.Bind(0);
