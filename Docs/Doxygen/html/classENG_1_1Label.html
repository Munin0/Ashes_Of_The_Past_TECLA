Detailed Description

UI label: a text drawn inside a rectangle.

A Label is an Object that draws a rectangle (with a background color and, optionally, a texture) and a text inside it. The text can be aligned to a corner or to the center of the label and moved with an offset.

Usage:

ENG::Label title("title", {300.0f, 40.0f});
title.SetText("Score: 0");
title.SetTextAlign(ENG::AlignText::TEXT_ALIGN_CENTER);
