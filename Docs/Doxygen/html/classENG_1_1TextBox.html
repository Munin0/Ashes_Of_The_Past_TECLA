Detailed Description

UI text box: a rectangle that shows a text the user can edit.

A TextBox is an Object that draws a rectangle (with a background color and an outline) and a text inside it. The text typed in the box is kept in an internal storage that can be read with GetTextStorage().

Usage:

ENG::TextBox nameBox("name_box", "", {300.0f, 40.0f});
nameBox.SetPosition({100.0f, 100.0f});
nameBox.SetTextColor(ENG::Color::White);
